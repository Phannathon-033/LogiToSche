# 📦 Logistics Invoice Benchmark Dataset (To_Testing)
**คลังภาพใบแจ้งหนี้โลจิสติกส์ 300 ฉบับที่มีข้อมูลครบถ้วนทั้ง 11 ฟิลด์หลัก (Full 11 Core Fields Benchmark)**

---

## 📌 สรุปข้อมูลชุดทดสอบ (Dataset Overview)
- **จำนวนเอกสารทั้งหมด:** 300 ฉบับ
- **ความสมบูรณ์ของฟิลด์ (Field Completeness):** 11/11 ฟิลด์ครบ 100% ทุกฉบับ (300/300)
- **การเรียงลำดับไฟล์ (Ranking 1-300):** เรียงตามลำดับความสมบูรณ์และคุณภาพข้อมูลสูงที่สุดลงมา (คะแนนคุณภาพ 185 - 250)
  - `001_...png` = เอกสารที่มีฟิลด์ครบถ้วน ชัดเจน และมีคุณภาพข้อมูลสูงสุด
  - `300_...png` = เอกสารอันดับที่ 300 ที่ยังคงมีครบทั้ง 11 ฟิลด์หลัก
- **รูปแบบไฟล์:**
  - ไฟล์ `.png` อยู่ในโฟลเดอร์หลัก `To_Testing` (สามารถเปิดดูในระบบ Windows, เว็บบราวเซอร์ และอัปโหลดเข้าหน้าเว็บ LogiToSche ได้ทันที)
  - ไฟล์ `.tif` ต้นฉบับถูกจัดเก็บไว้ในโฟลเดอร์ย่อย `tif_originals/` พร้อมใส่เลขลำดับ 001-300 ตรงกัน

---

## 🎯 มาตรฐาน 11 ฟิลด์หลัก (11 Core Logistics Fields Standard)
1. `document_type` (ประเภทเอกสาร: invoice)
2. `document_number` (เลขที่ใบแจ้งหนี้ / Invoice No.)
3. `document_date` (วันที่ออกเอกสาร / Invoice Date: YYYY-MM-DD)
4. `sender` (ผู้ส่งสินค้า / ผู้ขาย / ออกใบแจ้งหนี้)
5. `receiver` (ผู้รับสินค้า / ผู้ซื้อ / ปลายทาง)
6. `origin` (ต้นทาง / ที่อยู่ผู้ส่งสินค้า)
7. `destination` (ปลายทาง / ที่อยู่ผู้รับสินค้า)
8. `reference_number` (เลขที่อ้างอิง / Ref No. / PO No.)
9. `unit_price` (ราคาต่อหน่วย)
10. `total_amount` (ยอดเงินรวม)
11. `currency` (สกุลเงิน เช่น USD)
