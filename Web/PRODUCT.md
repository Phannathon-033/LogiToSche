# Product

## Register

product

## Users
Logistics operators, document processors, data entry teams, and logistics managers who need to extract structured JSON data from logistics documents (Invoices, Bills of Lading, Packing Lists, POs) with speed and precision.

## Product Purpose
Convert unstructured or semi-structured logistics documents into validated, high-confidence JSON schema output with human-in-the-loop verification for low-confidence fields.

## Brand Personality
Professional, precise, efficient, high-confidence, clean.

## Anti-references
Cluttered legacy ERP screens, low-contrast washed-out text, decorative non-functional glassmorphism, side-stripe card borders, generic SaaS templates.

## Design Principles
1. **Precision & Hierarchy**: Key actions and data fields are visually distinct with clear structural priority.
2. **High-Contrast Readability**: Essential text and labels use strong, legible contrast ratios without soft-gray illegibility.
3. **Structured Grid Rhythm**: Data density is managed using structured, predictable multi-column layouts rather than messy card nesting.
4. **Immediate Status Feedback**: Processing states, confidence levels, and manual review triggers stand out instantly with explicit semantic colors.

## Accessibility & Inclusion
WCAG AA contrast compliance (≥4.5:1 for body copy), explicit focus rings, clear font hierarchy, and responsive grid layouts.
