1

โคลนโปรเจกต์ (Git Clone) และเข้าสู่โฟลเดอร์ Web

ดาวน์โหลดซอร์สโค้ดทั้งหมดลงในเครื่องของคุณ

เปิด Terminal หรือ PowerShell ในโฟลเดอร์ที่คุณต้องการบันทึกโปรเจกต์ แล้วรันคำสั่ง: 

git clone https://github.com/Phannathon-033/LogiToSche.git
cd LogiToSche/Web
2

ตั้งค่าคอนฟิก Environment Variables (.env)

คัดลอกไฟล์คอนฟิกพื้นฐานสำหรับ Frontend และ Backend

คัดลอกไฟล์ .env.example ไปเป็น .env ทั้งใน Root และ Backend (ค่าเริ่มต้นเป็น Open Dev Mode รันได้ทันทีโดยไม่ต้องใส่ Token):

สำหรับ Windows (PowerShell หรือ CMD): 
copy .env.example .env
copy backend\.env.example backend\.env
3

สร้าง Virtual Environment และติดตั้งไลบรารี Python

ติดตั้ง PyTorch, PaddleOCR, Transformers, openpyxl ฯลฯ
3.1 สร้าง Virtual Environment ในโฟลเดอร์ backend:
python -m venv backend/.venv
3.2 เลือกลักษณะการติดตั้งไลบรารีตามสเปกเครื่องของคุณ:
ทางเลือกที่ 1: เครื่องมี NVIDIA GPU (แนะนำ ⭐) CUDA 12.x

ติดตั้ง PyTorch GPU + PaddleOCR GPU เพื่อความเร็วสูงสุด (16 tokens/sec):

backend\.venv\Scripts\pip.exe install --upgrade pip
backend\.venv\Scripts\pip.exe install -r backend\requirements.txt
ทางเลือกที่ 2: โหมด CPU (ไม่มี NVIDIA GPU) CPU Only

สำหรับแล็ปท็อปทั่วไปหรือ Mac ที่ต้องการรันแบบทดสอบพื้นฐาน:

backend\.venv\Scripts\pip.exe install --upgrade pip
backend\.venv\Scripts\pip.exe install -r backend\requirements-cpu.txt
4

ติดตั้งไลบรารี Frontend (Node.js Modules)

ติดตั้ง React, Tailwind, Lucide Icons และ Vite

ในโฟลเดอร์ Web ให้รันคำสั่ง:

npm install
5

วิธีรันระบบ (Starting Services)

เลือกวิธีที่สะดวกที่สุดสำหรับคุณ
✨ วิธีที่ 1 (สะดวกที่สุด - 1-Click เปิด 3 หน้าต่างอัตโนมัติ) แนะนำ

ดับเบิ้ลคลิกไฟล์ scripts\run-all-windows.bat หรือพิมพ์คำสั่งนี้ใน Terminal:

npm run dev:windows

*คำสั่งนี้จะเปิด 3 หน้าต่าง CMD แยกกันให้ทันที: (1) Frontend 5173, (2) Gateway 8000, (3) SLM Model 8001

💻 วิธีที่ 2: รันแยก 3 Terminal (สำหรับผู้ที่ต้องการดู Log แต่ละส่วนอย่างละเอียด)
Terminal 1: รัน SLM Model Service (Port 8001) โมเดล Qwen2.5-1.5B
backend\.venv\Scripts\python.exe -m uvicorn slm_app:app --host 0.0.0.0 --port 8001
Terminal 2: รัน AI Gateway & OCR Service (Port 8000) PaddleOCR Engine
backend\.venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000
Terminal 3: รัน Vite Frontend (Port 5173) Web UI
npm run dev
6

การทดสอบประเมินผล K-Fold และดาวน์โหลด Excel (.xlsx)

ขั้นตอนการรันประเมิน 300 ฉบับและนำผลไปเขียนรายงานวิทยานิพนธ์
1 เปิดหน้าเว็บ

เปิดบราวเซอร์ไปที่ http://localhost:5173 แล้วกดเลือกเมนู "ประเมินผล K-Fold Cross-Validation"

2 เลือกโหมดประเมิน

เลือกโหมด 5-Fold Cross-Validation (ครบ 300 ฉบับ) หรือทดลองแบบ ทดสอบสด 1 ฉบับ (Single Doc) เพื่อดูความเร็ว

3 กดเริ่มและปล่อยรัน

คลิกปุ่ม "เริ่มประเมิน 5-Fold ครบ 300 ฉบับ" ระบบจะรันใน Background ปล่อยเครื่องทิ้งไว้ประมาณ 1 ชม. ได้เลย ไม่หลุด timeout

4 ดาวน์โหลด Excel

เมื่อครบ 300 ฉบับ จะมีปุ่มสีเขียว "ดาวน์โหลดรายงานสรุป Excel (.xlsx)" ปรากฏขึ้นมา สามารถกดรับไฟล์สรุป 4 ชีตได้ทันที

💡 หรือดาวน์โหลดไฟล์ Excel รายงานล่าสุดผ่าน Direct URL: สามารถคลิกลิงก์เพื่อดาวน์โหลดไฟล์ผลการประเมิน 4 ชีตได้โดยตรง:
📥 ดาวน์โหลด Excel จาก API

คำถามและวิธีแก้ปัญหาที่พบบ่อย (Troubleshooting & FAQs)

🔴 ปัญหาที่ 1: พอร์ตถูกใช้งานอยู่ (Port 8000, 8001 หรือ 5173 in use) ▼

เกิดจากมีเซอร์วิสเดิมค้างอยู่ ให้รันคำสั่ง PowerShell นี้เพื่อปิดโปรเซสที่ค้าง:

npm run stop

หรือค้นหาและปิดพอร์ตเฉพาะเจาะจง:

Get-NetTCPConnection -LocalPort 8000, 8001, 5173 -ErrorAction SilentlyContinue | Select-Object LocalPort, OwningProcess
🔴 ปัญหาที่ 2: Activate.ps1 cannot be loaded (Execution Policy Error) ▼

เป็นระบบความปลอดภัยเริ่มต้นของ Windows PowerShell ให้แก้โดยรันคำสั่งนี้ครั้งเดียวใน PowerShell:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
🔴 ปัญหาที่ 3: CUDA Out of Memory (การ์ดจอ VRAM ไม่พอ) ▼

โมเดล Qwen2.5-1.5B (FP16) ใช้ VRAM ประมาณ 3.0 GB หากในเครื่องมีโปรแกรมอื่นกินการ์ดจอ (เช่น เกม, โปรแกรมจำลอง, แท็บบราวเซอร์จำนวนมาก) ให้ปิดโปรแกรมเหล่านั้นก่อนรัน หรือปรับใน backend/.env:

LOGIAI_SLM_DEVICE=cpu LOGIAI_OCR_DEVICE=cpu
ℹ️ ข้อมูล: การดาวน์โหลดโมเดลครั้งแรก (Initial Model Download) ▼

เมื่อรันเซอร์วิสครั้งแรก ระบบจะดาวน์โหลดน้ำหนักโมเดล Qwen/Qwen2.5-1.5B-Instruct ขนาด ~3.1 GB จาก Hugging Face และโมเดล PaddleOCR Thai+English โดยอัตโนมัติ ซึ่งจะถูกบันทึกแคชไว้ในเครื่อง ทำให้ในการเปิดรอบถัดไปโมเดลจะโหลดขึ้นมาได้ทันทีในเวลาเพียง 2–4 วินาที
